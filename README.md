# chronopath-site

Public pages for Chronopath, served by GitHub Pages: home, support, and the privacy policy.

- [Home Page](https://chronopath.damiark.com)
- [Support Page](https://chronopath.damiark.com/support)
- [Privacy Policy Page](https://chronopath.damiark.com/privacy)

Plain static HTML, no build step, no Jekyll (`.nojekyll`). The privacy text is the same as `PRIVACY_POLICY.md` in the (private) game repo; when one changes, change the other.
